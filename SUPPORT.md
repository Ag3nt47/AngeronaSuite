# Support

## Setup and usage questions

Use GitHub Discussions when available, or open a feature/support request with
the provided issue form. Include the Angerona version, operating system,
edition (Protect or Observe/Detect), installation method, and the smallest safe
reproduction. Remove usernames, hostnames, paths, IP addresses, command lines,
credentials, and private telemetry before posting.

## Bugs

Use the bug-report form. Attach only synthetic or manually redacted screenshots
and logs. State whether the issue reproduces with motion disabled and whether it
affects the Classic dashboard, Flow dashboard, or both.

## Security vulnerabilities

Do not open a public issue. Follow [SECURITY.md](SECURITY.md) and use GitHub's
private vulnerability-reporting workflow.

Support is community/maintainer best effort. Angerona is not an emergency
response service; if a real intrusion is in progress, follow your incident
response plan and contact an authorized security professional.
