# Angerona 1.16.0 network performance and maintained-tool updates

**Source preview · 15 November 2026**

Angerona 1.16.0 adds bounded connection-performance metrics and a daily,
review-gated update lifecycle for maintained GitHub tools. It also moves the
managed Zero Breach integration to the reviewed v3.0.2 release.

This is a source-preview version. Windows Protect and macOS/Linux Observe or
Detect retain their existing authority and deployment differences. A speed
result, repository check or scanner metadata self-test is not a protection
percentage, host-clean verdict, signed-release acceptance or evidence that every
upstream product is installed.

## System Pulse connection performance

The CPU performance card and its detail view now show:

- the active connection type, including Wi-Fi, Ethernet and recognized platform
  alternatives;
- estimated download and upload capacity in Mbps; and
- current aggregate network throughput as a percentage of the most recent
  measured capacity.

The first estimate starts after the dashboard is available. A new estimate is
made once per hour while the application remains open. Offline and failed checks
stay visible without blocking System Pulse. Live throughput continues to update
from local interface counters.

Each estimate is deliberately bounded to a 2 MiB download and a 512 KiB upload
of zero bytes against Cloudflare's speed-test service. It is not a substitute for
an ISP benchmark: Wi-Fi conditions, routing, server distance, concurrent traffic
and the bounded sample can affect the result. Set
`ANGERONA_SPEED_TEST_DISABLED=1` before launch to disable the active test.

## Daily maintained GitHub-tool checks

The optional daily tool preference checks the fixed canonical repositories for:

1. Zero Breach Toolkit;
2. Atomic Red Team;
3. SigmaHQ rules;
4. Sysmon Modular;
5. YARA-X;
6. MITRE Caldera;
7. Velociraptor; and
8. Wazuh.

Discovery uses fixed GitHub API endpoints and fixed reviewed branch names. It
does not follow repository-supplied installers, commands or redirect targets.
Automatic attempts are limited to once per day while Angerona is open. Operators
can run the same cross-platform operation outside the GUI with:

```text
python tools/daily_github_tool_updates.py
```

The integration type determines what happens next:

- **Managed scanner:** Zero Breach can be prepared and metadata-tested only when
  the stable release's version, commit, asset URL, size and SHA-256 exactly match
  Angerona's reviewed catalog.
- **Inert data:** a newer installed Atomic Red Team, Sigma, Sysmon Modular or
  YARA-X commit creates an immutable review request. It is not activated merely
  because upstream changed.
- **External product:** Caldera, Velociraptor and Wazuh are reported, not silently
  downloaded, installed, restarted or replaced.

These boundaries prevent a compromised or simply incompatible upstream release
from becoming automatic code-execution authority. A future Zero Breach release
must first receive a new reviewed Angerona pin.

## Zero Breach Toolkit v3.0.2

The complete upstream v3.0.2 single-file scanner is bundled unchanged with its
license, notices, detached-signature material and reviewed checksum:

- upstream commit: `2525377788feb8335052ba08981f37239091307a`;
- asset size: `7,879,062` bytes; and
- SHA-256: `0b6df5f02c6b13256b735bfb55c1ef0a31ff0c762550910be9f66b4f5090dafb`.

Angerona runs only the metadata self-test during automatic preparation. It does
not start a host scan, grant elevation or import the upstream module into Core or
the GUI interpreter. A recognized older managed installation is preserved for
rollback review rather than silently deleted.

## Privacy and network use

Both new network operations are optional and documented in [Privacy](../../PRIVACY.md):

- System Pulse sends bounded test traffic to Cloudflare when enabled; and
- the daily tool check requests public release or branch metadata from GitHub.

Normal public-service metadata such as source IP address, request timing and
user-agent information is visible to those services. Angerona does not include
local filenames, alerts, scan findings or host inventory in these requests.

## Validation scope

The feature revision passed focused System Pulse and dashboard tests, updater,
configuration and setup tests, curated-scanner and adapter tests, migration and
settings checks, Ruff, compile checks and documentation-drift validation. The
real macOS source installation prepared v3.0.2 and completed its supervised
metadata self-test without starting a host scan. The guarded publisher proved
the feature revision on public `main` and verified all README image bytes.

These focused groups overlap and are not presented as a unique full-suite total.
Hosted CI and security workflows remain exact-commit evidence. Their badges and
run pages, not this note, report the current public revision's final result.

## Upgrade notes

- Existing speed data starts unknown and is populated after the first successful
  bounded estimate.
- Daily application-update checks and daily maintained-tool checks remain
  separate preferences.
- An explicit Zero Breach uninstall remains respected until an operator restores
  the managed scanner.
- No existing external Caldera, Velociraptor or Wazuh deployment is changed.
- The downloadable Word/PDF manual remains the older 1.15.0 edition; the
  [readable manual](../master-manual.md) and this source companion describe the
  current source preview.
