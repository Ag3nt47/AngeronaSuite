## Confirmed findings and changes

- **A-01 — normal telemetry escalated process priority.** `dynamic_resource.py` counted INFO/health/passive events toward the incident threshold. Its stop caller restored NORMAL before signaling the worker, allowing an in-flight escalation to win, and also overwrote a pre-existing non-NORMAL priority. Fixed: count only `is_active_threat` HIGH/CRITICAL events; use bounded 4,096-entry arrival history and monotonic time; serialize escalation against stop; restore the exact original priority from the retiring worker's `finally`. Inert tests simulate stop inside the priority setter and a worker exception. No OS priority changes occur in tests.
- **A-02 — non-object cloud JSON could terminate corroboration.** Truthy JSON lists/scalars passed `_extract_json`, then `run` called `.get`. Fixed: require a bounded JSON object with allowed verdict, finite confidence in [0,1], and bounded nonempty justification. Drop uncontracted fields. Malformed replies remain explicitly unverified; the next event is still processed. The module remains opt-in with existing redaction and hourly call cap.
- **A-03 — uncertain reversible Combat effects incorrectly terminalized.** Before the change, `_block_program` could retain an applied rule after process identity drift plus failed deletion but still record terminal failure; partial IP/host isolation cleanup ignored deletion failures, and suspend postcondition failure could lose custody of the uncertain effect. Seven inert regressions failed before remediation. Fixed: all those paths use the existing orphan/undo-intent/verified-undo journal protocol, close the original intent only after proven restoration and a durable undo receipt, and trip the mutation circuit on uncertainty. Firewall existence now has three outcomes (present, proven absent, unavailable), so failed queries cannot authorize a clean undo or startup recovery. Suspend identity drift never causes a blind resume. Fifteen new regressions cover complete-intent rollback, partial add failures, query failures, absent rules, unknown process status, startup replay and failed undo receipts. The existing PID-drift fixture now models firewall existence instead of consulting the real machine.
- **A-10 — live Defender channel replacement was not revalidated.** A fake channel first committed record 1. During the next live poll its record-1 XML was replaced and a new record 2 appeared. Before remediation the reader committed 2 with `continuity_gaps=0`, health 100; both between-poll and during-query regression cases failed. Fixed: each live page verifies the committed anchor before/after the query, validates the terminal row against the channel, and rechecks the prior anchor after that read. Known replacement preserves the old cursor, persists incomplete coverage and blocks fallback/rebase pending explicit continuity recovery. Transient query errors stay retryable and cannot prove absence. Reproduction and tests use fake readers and disposable SQLite only; ordinary pagination/restart remain covered.
- **A-26 — remote evidence could complete a local Lattice response threshold.** The independent peer reproduced two local MEDIUM observations plus one remote observation carrying the `process_id` alias producing a local response-authorized contract. Fixed by rejecting `is_remote_observe_only` input before any correlation or entity retention. The new `test_evidence_lattice_remote_boundary.py` covers PID aliases, both remote markers, same-IP correlation, local positive controls and a 599-entity remote flood. Peer validation: **56 passed** with semantic-response, detector-observation and remote-bridge suites; Ruff clean. No response action was executed.
- **Conditional trust boundary resolved as a supported-mode distinction:** Combat accepts an absent/unarmed EventBus for standalone/portable tests. Normal GUI and headless entrypoints arm their EventBus immediately after construction. No supported production path bypassing that initialization was established; the unarmed testing mode is not reported as a production exploit.

Targeted validation: `tests/test_group_a_priority_cloud_regressions.py`, `test_v12_module_selftests.py`, `test_provider_credentials.py`, and `test_cycle4_round2_cloud_privacy.py`: **35 passed**. `test_combat_uncertain_reversible_mutations.py`, `test_adversary_combat.py`, `test_adversary_combat_boundaries.py`, `test_adversary_combat_journal.py`, and `test_combat_startup_recovery_tool.py`: **70 passed**. `test_defender_live_continuity.py`, `test_defender_modern_eventlog.py`, `test_defender_witness_cache.py`, `test_cycle26_defender_remediation_boundary.py`, `test_cycle27_remaining_a_remediation.py`, and `test_cycle27_remaining_a_independent_reattack.py`: **85 passed**. The independent Lattice fix has **56 passing** focused cases. Ruff passed the changed product/test files. Initial long parametrized IDs exceeded the Windows temporary-path limit; the fixture now uses short IDs. ## Remaining confirmed medium-priority correctness/resource limits

These are bounded review findings rather than claims that the entire product has been repaired. Product source was frozen after the scoped fixes; additional assignments/results supersede these entries explicitly.

- **ARP unapproved-history retention:** `_unknown_alerted` retains distinct `(IP, MAC)` observations without a cap/expiry, including real-time packet input. A 10,000-observation inert replay retained all 10,000 keys. This can grow with sustained local-network churn; it never promotes those observations into the approved trust baseline.
- **Technique-list omission:** both Compliance Mapper and Daily Briefing ignore the common `mitre_tags` list field. A fixture containing only `mitre_tags=["T1059.001"]` produced an empty mapped technique and empty top-technique list. Compliance still declares relevance-only semantics and its coverage counters do not measure this semantic omission.
- **Deception feed replacement:** replacement by a different, larger log preserves the old text-stream offset. A new credential/discovery prefix was skipped in an inert atomic-replacement fixture. The five-second file-canary observer remains independent. The tail also reads all newly appended lines into memory, so work scales with feed growth.
- **Counter-Agentic endpoint false positive:** the port watcher matches port numbers without checking address locality. A fixture with local `192.0.2.1:5555` and remote `203.0.113.9:11434` counted as local inference access (`port_connections=1`, `unexpected=1`). It emits detection-only evidence and cannot directly contain that process.
- **Daily Briefing narrative boundary:** its advisory model path lacks AI Triage's model-attestation requirement and falls back to raw facts if telemetry neutralization raises. Its output is advisory and does not grant action authority, but untrusted model/data input can affect narrative accuracy. Use the deterministic fallback when the protected AI path is unavailable.
